 # Python Libraries I Am Learning

I am trying to learn these Python libraries because my college skipped them.

## Direct Resources

1. **NumPy:** [Keith Galli – NumPy Tutorial](https://www.youtube.com/results?search_query=Keith+Galli+NumPy+Tutorial+for+Beginners) — Covers arrays, indexing, slicing, mathematical operations, reshaping, and linear algebra.
2. **Pandas:** [Corey Schafer – Pandas Tutorials](https://www.youtube.com/results?search_query=Corey+Schafer+Pandas+Tutorial) — Covers DataFrames, Series, filtering, grouping, and data manipulation.
3. **Matplotlib:** [Corey Schafer – Matplotlib Tutorials](https://www.youtube.com/results?search_query=Corey+Schafer+Matplotlib+Tutorial) — Covers different types of graphs, figures, axes, labels, and customization.
4. **SciPy:** [Great Learning – SciPy Tutorial](https://www.youtube.com/results?search_query=Great+Learning+SciPy+Python+Tutorial) — A good starting point for scientific computations.
